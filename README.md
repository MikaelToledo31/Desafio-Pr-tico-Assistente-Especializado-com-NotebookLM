# TaskFlow AI – Assistente Especialista com NotebookLM

Este projeto foi desenvolvido como atividade de pós-graduação com o objetivo de criar um produto digital estruturado e configurar um assistente especialista utilizando o Google NotebookLM.

O produto idealizado, **TaskFlow AI**, é uma plataforma SaaS voltada para pequenas empresas e imobiliárias, focada em organização operacional e automação de processos repetitivos.

O repositório contém dois documentos principais:

- **Documento do Produto (PDF):** descreve o escopo, funcionalidades, público-alvo, planos, benefícios e limitações do TaskFlow AI.
- **Prompt do Assistente (PDF):** define a personalidade, comportamento e regras do assistente especialista, utilizando técnicas de Engenharia de Prompt como **Zero-Shot**, **Few-Shot** e **Chain of Thought**.

## Objetivo do Projeto
Criar um assistente confiável e transparente, capaz de responder perguntas exclusivamente com base na documentação oficial do produto, garantindo precisão, integridade e comunicação clara.

## Tecnologias e Conceitos Aplicados
- Inteligência Artificial
- Google NotebookLM
- Engenharia de Prompt
- Gestão de Produtos
- IA para Alta Performance

Projeto desenvolvido para fins acadêmicos.
